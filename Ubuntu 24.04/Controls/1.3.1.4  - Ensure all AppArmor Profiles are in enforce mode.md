# 35539 - Ensure all AppArmor Profiles are in enforce mode  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.9.1.1 | CIS Benchmark | CIS 1.3.1.4
**Stato:** Pass
**Data del fix:** 26 Maggio 2026 

## Requisito del Controllo
Tutti i profili AppArmor presenti sul sistema devono essere in **enforce mode**.  
Questo garantisce che le policy di Mandatory Access Control (MAC) siano attive e che ogni applicazione sia confinata secondo le regole definite, riducendo significativamente il rischio di exploit e movimenti laterali

## Fix Applicato
- Installato `apparmor-utils` (se mancante)
- Messo in enforce mode tutti i profili presenti in `/etc/apparmor.d/`
- Ricaricato AppArmor per applicare le modifiche

**Comandi eseguiti:**
```bash
# Installazione degli strumenti di gestione AppArmor
sudo apt install apparmor-utils -y

# Mette tutti i profili in enforce mode
sudo aa-enforce /etc/apparmor.d/*

# Ricarica il servizio AppArmor
sudo systemctl reload apparmor
```
## Motivazione
Anche se un sito può adottare policy più restrittive rispetto al default, è fondamentale assicurarsi che **tutte le policy esistenti** siano realmente attive. Lasciare profili in complain mode equivale a non avere alcuna protezione.
## Verifica
```bash
# Stato completo di AppArmor
sudo apparmor_status

# Verifiche specifiche richieste dal CIS
sudo apparmor_status | grep -E "profiles are in enforce mode|profiles are loaded|processes are unconfined|profiles are in complain mode|profiles are in kill mode"
```

**Output atteso:**
- Numero di profili in enforce mode > 0
- Numero totale di profili caricati > 0
- 0 processi unconfined
- 0 profili in complain mode
- 0 profili in kill mode
