# 35545 - Ensure Apport is disabled  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.13.1.3 | CIS Benchmark | CIS-1.5.5
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
Il servizio Apport (Automatic Error Reporting) deve essere completamente disabilitato.  
Apport raccoglie crash report, core dump e log che possono contenere dati sensibili (password, chiavi private, numeri di carte, ecc.).

## Motivazione
Apport rappresenta un rischio per la riservatezza dei dati su un server di produzione. Non è necessario in ambiente server e va disattivato per ridurre la superficie di attacco.

## Fix Applicato
- Stop, disable e mask del servizio `apport`
- Configurazione esplicita `enabled=0` in `/etc/default/apport`

**Comandi eseguiti:**
```bash
sudo systemctl stop apport.service
sudo systemctl disable apport.service
sudo systemctl mask apport.service

sudo tee /etc/default/apport > /dev/null << EOF
enabled=0
EOF
```

## Verifica 
```bash
sudo systemctl is-enabled apport.service     # → disabled
sudo systemctl is-active apport.service      # → inactive
sudo cat /etc/default/apport                 # → enabled=0
```
