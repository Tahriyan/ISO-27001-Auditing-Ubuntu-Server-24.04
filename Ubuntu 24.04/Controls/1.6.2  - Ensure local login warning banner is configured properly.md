
# 35547 - Ensure local login warning banner is configured properly  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** CIS Benchmark | CIS-1.6.2
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
Il file `/etc/issue` (banner visualizzato prima del login locale) deve contenere **solo un messaggio di avvertimento legale** e **non deve includere** alcuna informazione sul sistema operativo

con `uname -a`.

## Fix Applicato
- Sostituito il contenuto di `/etc/issue` con un banner pulito e professionale
- Creato/aggiornato anche `/etc/issue.net` (usato da SSH)

**Comandi eseguiti:**
```bash
# Banner per login locale (console)
sudo tee /etc/issue << 'EOF'
Authorized access only. All activity may be monitored and reported.
EOF

# Banner per login remoto (SSH)
sudo tee /etc/issue.net << 'EOF'
Authorized access only. All activity may be monitored and reported.
EOF
```

## Motivazione
I banner di login devono informare gli utenti dello status legale del sistema (proprietà, monitoraggio, divieto di accesso non autorizzato)

## Verifica
```bash
# Verifica che non ci siano informazioni di OS nel banner
sudo cat /etc/issue
sudo cat /etc/issue.net

# Check CIS specifico
sudo grep -E '\\v|\\r|\\m|\\s|Debian|Ubuntu|Linux' /etc/issue /etc/issue.net || echo "Nessuna informazione di sistema presente"
```
