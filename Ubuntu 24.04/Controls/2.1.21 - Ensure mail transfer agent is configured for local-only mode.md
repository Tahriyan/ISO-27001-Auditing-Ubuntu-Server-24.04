
# 35581 - Ensure mail transfer agent is configured for local-only mode

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.13.1.3 | CIS Benchmark  | CIS-2.1.21
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
L’MTA (Mail Transfer Agent), come Postfix, deve essere configurato per processare **solo mail locali**.  
Questo si ottiene impostando `inet_interfaces = 127.0.0.1, [::1]` (o `loopback-only`) in `/etc/postfix/main.cf` in modo che il demone ascolti **esclusivamente** su localhost e non su interfacce di rete esterne.

## Fix Applicato
- Modificata la riga `inet_interfaces` nel file di configurazione di Postfix con il formato esplicito accettato dal controllo Wazuh  
- Riavviato il servizio Postfix

**File configurati:**
- `/etc/postfix/main.cf`

**Comandi eseguiti:**
```bash
# Modifica precisa della configurazione (formato che soddisfa il regex di Wazuh)
sudo sed -i 's/^inet_interfaces.*/inet_interfaces = 127.0.0.1, [::1]/' /etc/postfix/main.cf

# Riavvio del servizio
sudo systemctl restart postfix
```

## Motivazione
Il software per tutti i Mail Transfer Agents è complesso e ha una lunga storia di problemi di sicurezza. Mentre è importante garantire che il sistema possa processare messaggi di posta locali, non è necessario che il demone MTA ascolti su una porta di rete a meno che il server non sia destinato a essere un mail server che riceve e processa mail da altri sistemi.  
La configurazione `local-only` riduce significativamente la superficie di attacco senza impattare Nextcloud e gli altri servizi che necessitano di inviare mail locali.

## Verifica 
```bash
# Verifica configurazione Postfix
grep '^inet_interfaces' /etc/postfix/main.cf

# Verifica porte in ascolto (deve mostrare solo loopback)
ss -lntu | grep -E ':25|:465|:587'
```

**Output atteso:**
```
inet_interfaces = 127.0.0.1, [::1]
tcp   LISTEN   0   100   127.0.0.1:25   0.0.0.0:*
tcp   LISTEN   0   100   [::1]:25       [::]:*
```
