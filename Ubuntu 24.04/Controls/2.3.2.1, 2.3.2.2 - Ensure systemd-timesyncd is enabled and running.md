# 35588/35589- Ensure systemd-timesyncd is enabled and running

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.12.4.4 | CIS-2.3.2.1, 2.3.2.2
**Data:** 26 Maggio 2026 
**Stato:** Pass (Compliant - False Positive su Wazuh SCA)

## Requisito del Controllo
Configurazione di systemd-timesyncd per la sincronizzazione temporale affidabile.

## Fix Applicato
**comandi eseguiti:**
 - Modifica del file: `/etc/systemd/timesyncd.conf` con la seguente configurazione:
 
```ini
NTP=time.cloudflare.com 
FallbackNTP=ntp.ubuntu.com 
```

```bash
sudo systemctl restart systemd-timesyncd 
sudo systemctl enable systemd-timesyncd
```

## Motivazione
Garantisce che i log e gli eventi abbiano timestamp coerenti (fondamentale per audit e indagini forensi)

## Verifica
```bash
sudo systemctl status systemd-timesyncd.service
timedatectl status
```
