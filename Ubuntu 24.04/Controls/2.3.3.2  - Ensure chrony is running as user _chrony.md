# 35591/35592- Ensure chrony is running as user `_chrony`

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.12.4.4 | CIS Benchmark | CIS-2.3.3.2
**Data:** 26 Maggio 2026
**Stato:** Pass

## Requisito del Controllo
Il servizio `chronyd` deve essere eseguito con il minimo privilegio necessario, utilizzando l’utente dedicato `_chrony` (non root).  Per ridurre il rischio di escalation di privilegi e garantire che i timestamp dei log e degli eventi siano coerenti e attendibili per finalità di audit e indagini forensi


## Fix Applicato
**Comandi eseguiti:**
```bash
# Installazione di chrony
sudo apt install chrony -y

# Assicura che il servizio giri come utente _chrony (configurazione di default su Ubuntu 24.04)
sudo tee -a /etc/chrony/conf.d/user.conf > /dev/null << EOF
user _chrony
EOF

# Abilitazione e avvio del servizio
sudo systemctl enable --now chrony
```

## Motivazione
Garantire che il servizio di sincronizzazione oraria (chrony) operi con privilegi minimi è fondamentale per:
- Ridurre la superficie di attacco
- Mantenere l’integrità dei timestamp nei log di sistema
- Supportare correttamente i processi di audit e compliance (ISO 27001 A.12.4.4)


## Verifica
```bash
# Verifica dello stato del servizio
sudo systemctl status chrony

# Verifica che chronyd stia girando come utente _chrony
ps -ef | grep chrony

# Verifica che systemd-timesyncd sia disabilitato (requisito CIS)
systemctl show systemd-timesyncd.service | grep -E 'LoadState|ActiveState'
```
