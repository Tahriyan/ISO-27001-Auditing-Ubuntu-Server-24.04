# 35604 - Ensure DCCP is disabled 

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.13.1.3 | CIS-3.2.1
**Data del fix:** 26 Maggio 2026  26 Maggio 2026
**Stato:** Pass

## Requisito del Controllo
Il kernel module **DCCP** (Datagram Congestion Control Protocol) deve essere disabilitato.  
DCCP è un protocollo di trasporto non comunemente utilizzato sui server di produzione e aumenta inutilmente la superficie di attacco del kernel.

## Fix Applicato
- Creato file di configurazione in `/etc/modprobe.d/` per impedire il caricamento del modulo
- Aggiunto sia `install /bin/false` che `blacklist` (best practice completa CIS)

**File creato:** `/etc/modprobe.d/dccp.conf`

**Comandi eseguiti:**
```bash
# Disabilita il caricamento del modulo DCCP
echo "install dccp /bin/false" | sudo tee /etc/modprobe.d/dccp.conf

# Aggiunge anche la blacklist
echo "blacklist dccp" | sudo tee -a /etc/modprobe.d/dccp.conf
```

## Motivazione
Se il protocollo DCCP non è necessario, è fortemente consigliato non installare o disabilitare completamente i relativi driver per ridurre la potenziale superficie di attacco. DCCP non fornisce consegna in ordine e non è richiesto nella maggior parte degli ambienti server.

## Verifica
```bash
# Verifiche CIS richieste
modprobe -n -v dccp                          # → install /bin/false

# Controllo che il modulo non sia caricato
lsmod | grep dccp || echo "DCCP non caricat"

# Verifica completa del file di configurazione
cat /etc/modprobe.d/dccp.conf
```

**Output atteso:**
- `install dccp /bin/false`
- Nessun modulo `dccp` presente in `lsmod`
