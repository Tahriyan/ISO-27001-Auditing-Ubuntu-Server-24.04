
# 35605 - Ensure TIPC is disabled  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.13.1.3 | CIS-3.2.2
**Data del fix:** 26 Maggio 2026
**Stato:** Pass

## Requisito del Controllo
Il kernel module **TIPC** (Transparent Inter-Process Communication) deve essere disabilitato.  
TIPC è un protocollo progettato per la comunicazione tra nodi di un cluster e non è necessario su un server di produzione standard.

## Fix Applicato
- Creato file di configurazione in `/etc/modprobe.d/` per impedire il caricamento del modulo
- Aggiunto sia `install /bin/false` che `blacklist` (best practice completa CIS)

**File creato:** `/etc/modprobe.d/tipc.conf`

**Comandi eseguiti:**
```bash
# Disabilita il caricamento del modulo TIPC
echo "install tipc /bin/false" | sudo tee /etc/modprobe.d/tipc.conf

# Aggiunge anche la blacklist
echo "blacklist tipc" | sudo tee -a /etc/modprobe.d/tipc.conf
```

## Motivazione
Se il protocollo TIPC non viene utilizzato, è fortemente consigliato impedire il caricamento del relativo kernel module per ridurre la superficie di attacco. Lasciare moduli di rete non comuni abilitati aumenta inutilmente i vettori di exploit possibili.

## Verifica
```bash
# Verifiche CIS richieste
modprobe -n -v tipc                          # → install /bin/false

# Controllo che il modulo non sia caricato
lsmod | grep tipc || echo "TIPC non caricato"

# Verifica completa del file di configurazione
cat /etc/modprobe.d/tipc.conf
```

**Output atteso:**
- `install tipc /bin/false`
- Nessun modulo `tipc` presente in `lsmod`
