# 35606 - Ensure RDS is disabled 

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.13.1.3 | CIS-3.2.3
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
Il kernel module **RDS** (Reliable Datagram Sockets) deve essere disabilitato.  
RDS è un protocollo di trasporto progettato per comunicazioni a bassa latenza tra nodi di cluster (sviluppato da Oracle) e non è necessario su un server di produzione standard.

## Fix Applicato
- Creato file di configurazione in `/etc/modprobe.d/` per impedire il caricamento del modulo
- Aggiunto sia `install /bin/false` che `blacklist` (best practice completa CIS)

**File creato:** `/etc/modprobe.d/rds.conf`

**Comandi eseguiti:**
```bash
# Disabilita il caricamento del modulo RDS
echo "install rds /bin/false" | sudo tee /etc/modprobe.d/rds.conf

# Aggiunge anche la blacklist
echo "blacklist rds" | sudo tee -a /etc/modprobe.d/rds.conf
```

## Motivazione
Se il protocollo RDS non viene utilizzato, è fortemente consigliato impedire il caricamento del relativo kernel module per ridurre la superficie di attacco. Lasciare moduli di rete non comuni abilitati aumenta inutilmente i vettori di exploit possibili.

## Verifica
```bash
# Verifiche CIS richieste
modprobe -n -v rds                          # → install /bin/false

# Controllo che il modulo non sia caricato
lsmod | grep rds || echo "RDS non caricato"

# Verifica completa del file di configurazione
cat /etc/modprobe.d/rds.conf
```

**Output atteso:**
- `install rds /bin/false`
- Nessun modulo `rds` presente in `lsmod`
- File di configurazione contenente sia la riga `install` che `blacklist`
