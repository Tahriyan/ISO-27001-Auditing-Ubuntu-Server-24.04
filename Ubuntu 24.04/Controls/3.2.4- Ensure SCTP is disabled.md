# 35607 - Ensure SCTP is disabled  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:**  ISO 27001:2013 A.13.1.3 | CIS-3.2.4
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
Il kernel module **SCTP** (Stream Control Transmission Protocol) deve essere disabilitato.  
SCTP è un protocollo di trasporto orientato ai messaggi che combina caratteristiche di TCP e UDP. Non è necessario su un server di produzione standard.

## Fix Applicato
- Creato file di configurazione in `/etc/modprobe.d/` per impedire il caricamento del modulo
- Aggiunto sia `install /bin/false` che `blacklist` (best practice completa CIS)

**File creato:** `/etc/modprobe.d/sctp.conf`

**Comandi eseguiti:**
```bash
# Disabilita il caricamento del modulo SCTP
echo "install sctp /bin/false" | sudo tee /etc/modprobe.d/sctp.conf

# Aggiunge anche la blacklist
echo "blacklist sctp" | sudo tee -a /etc/modprobe.d/sctp.conf
```

## Motivazione
Se il protocollo SCTP non viene utilizzato, è fortemente consigliato impedire il caricamento del relativo kernel module per ridurre la superficie di attacco. Lasciare moduli di rete non comuni abilitati aumenta inutilmente i vettori di exploit possibili.

## Verifica
```bash
# Verifiche CIS richieste
modprobe -n -v sctp                          # → install /bin/false

# Controllo che il modulo non sia caricato
lsmod | grep sctp || echo "SCTP non caricato"

# Verifica completa del file di configurazione
cat /etc/modprobe.d/sctp.conf
```

**Output atteso:**
- `install sctp /bin/false`
- Nessun modulo `sctp` presente in `lsmod`
- File di configurazione contenente sia la riga `install` che `blacklist`
