
# 35675 - Ensure password history is remembered  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:**  ISO 27001:2013 A.9.4.3 | CIS-5.3.2.4
**Data:** 26 Maggio 2026 
**Stato:** Pass (Compliant - False Positive su Wazuh SCA)

## Requisito del Controllo
Deve essere abilitato il modulo `pam_pwhistory.so` per memorizzare le password precedenti degli utenti e impedire il riutilizzo troppo frequente delle stesse (remember ≥ 5).


## Fix Applicato
- Abilitato `pam_pwhistory.so` **prima** della riga `pam_unix.so`
- Impostato `remember=24` (valore superiore al minimo richiesto di 5)
- Configurazione pulita e ordinata

**Contenuto attuale di `/etc/pam.d/common-password` (righe rilevanti):**
```bash
password requisite pam_pwquality.so
password requisite pam_pwhistory.so enforce_for_root try_first_pass use_authtok remember=24
password [success=1 default=ignore] pam_unix.so obscure use_authtok try_first_pass yescrypt remember=5
password requisite pam_deny.so
password required pam_permit.so
```

## Motivazione
L’utilizzo di password uniche e complesse aumenta il tempo e le risorse necessarie a un attaccante per comprometterle. La history delle password impedisce agli utenti di alternare ciclicamente tra un piccolo set di password.

## Verifica
```bash
grep -E '^password' /etc/pam.d/common-password
```

**Output ottenuto:**
```
password requisite pam_pwquality.so
password requisite pam_pwhistory.so enforce_for_root try_first_pass use_authtok remember=24
password [success=1 default=ignore] pam_unix.so obscure use_authtok try_first_pass yescrypt remember=5
password requisite pam_deny.so
password required pam_permit.so
```

**Verifiche CIS specifiche:**
- `pam_pwhistory.so` presente con `remember=24` → conforme (≥5)
- `pam_unix.so` contiene `success=1 default=ignore` e `use_authtok` → conforme
