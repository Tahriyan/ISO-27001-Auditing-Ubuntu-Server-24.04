
# 35678 - Ensure lockout for failed password attempts includes the root account  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.9.2.6 | CIS-5.3.3.1.3
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
La policy di lockout dopo tentativi di login falliti deve applicarsi **anche all’account root** (`even_deny_root`).  
Questo impedisce attacchi brute-force mirati all’account più privilegiato del sistema.

## Fix Applicato
- Editato `/etc/security/faillock.conf`
- Impostati:
  - `deny = 5` (massimo tentativi falliti)
  - `unlock_time = 900` (15 minuti di blocco automatico)
  - `even_deny_root` (applica il lockout anche a root)

**Comandi eseguiti:**
```bash
sudo nano /etc/security/faillock.conf
```

**Contenuto rilevante di `/etc/security/faillock.conf`:**
```conf
deny = 5
unlock_time = 900
even_deny_root
```

## Motivazione
Bloccare gli account (incluso root) dopo un numero definito di tentativi falliti mitiga gli attacchi di forza bruta. Senza `even_deny_root` l’account root rimarrebbe sempre accessibile anche dopo tentativi multipli.

## Verifica
```bash
# Verifiche richieste dal CIS
grep -E '^(even_deny_root|root_unlock_time|deny|unlock_time)' /etc/security/faillock.conf

# Verifica completa del file
cat /etc/security/faillock.conf
```

**Output atteso (condizione “any”):**
- Presenza della riga `even_deny_root`  
  **oppure**  
- `root_unlock_time` ≥ 60
