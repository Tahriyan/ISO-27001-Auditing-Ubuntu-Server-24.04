# 35679–35683 - password complexity requirements are configured  
  
**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.9.4.3 | CIS-5.3.3.2.1, 5.3.3.2.2, 5.3.3.2.3, 5.3.3.2.4, 5.3.3.2.5
**Stato:** Pass
**Data del fix:** 26 Maggio 2026

## Requisito del Controllo
La configurazione di `pwquality` deve imporre password complesse e sicure, impedendo:
- Riutilizzo di parti della password precedente (`difok`)
- Password troppo corte (`minlen`)
- Password con troppa poca varietà di caratteri (`minclass`)
- Sequenze ripetute o monotone (`maxrepeat`, `maxsequence`)

## Fix Applicato
- Editato il file principale `/etc/security/pwquality.conf`
- Impostati tutti i parametri di complessità in un’unica configurazione pulita

**File configurato:** `/etc/security/pwquality.conf`

**Contenuto rilevante:**
```conf
# Password complexity settings (CIS 5.3.3.2.x)
difok = 2          # (35679) Caratteri diversi dalla password precedente
minlen = 14        # (35680) Lunghezza minima
minclass = 4       # (35681) Almeno 4 classi (upper, lower, digit, special)
maxrepeat = 3      # (35682) Massimo 3 caratteri identici consecutivi
maxsequence = 3    # (35683) Massimo 3 caratteri sequenziali (es. 123, abc)
```

**Comandi eseguiti:**
```bash
sudo nano /etc/security/pwquality.conf
```

## Motivazione
L’uso di password complesse aumenta il tempo e le risorse necessarie a un attaccante per comprometterle tramite guessing o brute-force.  
La complessità della password è uno dei fattori principali che determina quanto tempo serve per crackarla.

## Verifica
```bash
# Verifica tutti i parametri
grep -E '^(difok|minlen|minclass|maxrepeat|maxsequence)' /etc/security/pwquality.conf

# Verifiche specifiche CIS
grep -E '^difok' /etc/security/pwquality.conf          # ≥ 2
grep -E '^maxsequence' /etc/security/pwquality.conf    # ≤ 3 e ≠ 0
```

**Output atteso:**
- Tutti i valori sopra riportati esattamente come configurati
