# 35687-35689 - Ensure password history remember, enforce_for_root and use_authtok are configured (pam_pwhistory)

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.9.4.3 / A.10.1.1 | CIS-5.3.3.3.1, 5.3.3.3.2, 5.3.3.3.3
**Versione:** 1.0.0 (2024)  
**Stato:** Pass (Compliant - False Positive su Wazuh SCA)  
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
- **35687**: `pam_pwhistory.so` deve avere `remember=24` (o superiore)
- **35688**: `pam_pwhistory.so` deve avere `enforce_for_root`
- **35689**: `pam_pwhistory.so` e `pam_unix.so` devono avere `use_authtok`

## Fix Applicato
- Configurata correttamente la riga `pam_pwhistory.so` con tutti i parametri richiesti
- Pulita la riga `pam_unix.so` rimuovendo `remember=5` (gestito ora da pam_pwhistory)

**File configurati:**
- `/etc/pam.d/common-password`

**Configurazione attuale:**
```bash
password requisite pam_pwquality.so
password requisite pam_pwhistory.so enforce_for_root try_first_pass use_authtok remember=24
password [success=1 default=ignore] pam_unix.so obscure use_authtok try_first_pass yescrypt
password requisite pam_deny.so
password required pam_permit.so
```

**Comandi eseguiti (riassunto):**
```bash
sudo cp /etc/pam.d/common-password /etc/pam.d/common-password.bak.$(date +%F)
sudo sed -i '/pam_unix.so/c\password [success=1 default=ignore] pam_unix.so obscure use_authtok try_first_pass yescrypt' /etc/pam.d/common-password
```

## Motivazione
Questi parametri impediscono il riutilizzo di password recenti (anche per root) e garantiscono un corretto flusso tra i moduli PAM durante il cambio password. La configurazione attuale soddisfa pienamente il requisito di sicurezza CIS 5.3.3.3.x.

Il fallimento su Wazuh è dovuto esclusivamente a regex obsoleti del controllo SCA e non a un problema reale di configurazione.

## Verifica 
```bash
# Verifica completa
grep '^password' /etc/pam.d/common-password

# Parametri richiesti
grep -o 'remember=[0-9]*' /etc/pam.d/common-password
grep -o 'enforce_for_root' /etc/pam.d/common-password
grep -o 'use_authtok' /etc/pam.d/common-password
```

**Output atteso:**
```
remember=24
enforce_for_root
use_authtok
use_authtok
```
