# 35695 - Ensure minimum days between password changes is configured  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.9.4.3 | CIS-5.4.1.2
**Data:** 26 Maggio 2026 
**Data del fix:** Pass

## Requisito del Controllo
Deve essere configurato un numero minimo di giorni tra un cambio password e l’altro (**PASS_MIN_DAYS > 0**).  
Questo impedisce agli utenti di cambiare ripetutamente la password per aggirare i controlli di history.

## Fix Applicato
- Configurato `PASS_MIN_DAYS 1` in `/etc/login.defs`
- Applicato il valore anche all’utente esistente `ubuntu` tramite `chage`

**Comandi eseguiti:**
```bash
# Configurazione globale (nuovi utenti)
sudo nano /etc/login.defs
# → PASS_MIN_DAYS 1

# Applicazione all'utente esistente ubuntu
sudo chage --mindays 1 ubuntu
```

## Verifica
```bash
grep '^PASS_MIN_DAYS' /etc/login.defs
# → PASS_MIN_DAYS 1

sudo awk -F: '($2 ~ /^\$.+\$/) {print $1 " → min_days=" $4}' /etc/shadow | grep -E 'min_days=0'
# (nessun output = tutti gli utenti conformi)
```
