# 35698 - Ensure inactive password lock is 45 days or less  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server 
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.9.4.3 | CIS-5.4.1.5
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
Gli account utente inattivi devono essere bloccati automaticamente dopo **al massimo 45 giorni** dalla scadenza della password (`INACTIVE ≤ 45`)  
Questo impedisce che account dimenticati o non più utilizzati rimangano accessibili indefinitamente

## Fix Applicato
- Configurato il valore di default per **nuovi utenti** (`useradd -D`)
- Applicato il valore anche all’**utente esistente** `ubuntu`

**Valore impostato:** `30` giorni (più restrittivo del massimo consentito di 45)

**Comandi eseguiti:**
```bash
# Default per tutti i nuovi utenti
sudo useradd -D -f 30

# Applicazione all'utente esistente ubuntu
sudo chage --inactive 30 ubuntu
```

## Motivazione
Gli account inattivi rappresentano un rischio elevato perché gli utenti non controllano più tentativi di login falliti o altre anomalie. Bloccare automaticamente questi account riduce la finestra di opportunità per attacchi

## Verifica
```bash
# 1. Verifica default per nuovi utenti
useradd -D | grep '^INACTIVE'

# 2. Verifica utenti esistenti (campo INACTIVE in /etc/shadow)
sudo awk -F: '($2 ~ /^\$.+\$/) {print $1 " → inactive=" $7}' /etc/shadow

# 3. Verifica CIS specifica (nessun utente con inactive > 45 o -1)
sudo awk -F: '($2 ~ /^\$.+\$/) && ($7 > 45 || $7 < 0) {print $1 " → inactive=" $7}' /etc/shadow
```

**Output atteso:**
- `INACTIVE=30`
- `ubuntu → inactive=30`
- Nessun utente con valore > 45 o negativo
