# 35703 - Ensure root user umask is configured 

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.9.1.1 | CIS-5.4.2.6
**Versione:** 1.0.0 (2024)
**Stato:** Pass
**Data del fix:** 26 Maggio 2026

## Requisito del Controllo
L’`umask` dell’utente root deve essere impostato a **0027** o più restrittivo (es. 0077) sia in `/root/.bash_profile` che in `/root/.bashrc`.  
Questo garantisce che i file e le directory creati da root non abbiano permessi eccessivi per group e other.

## Fix Applicato
- Verificato che non esistessero righe `umask` precedenti
- Aggiunto `umask 0027` in entrambi i file di configurazione della shell di root

**File configurati:**
- `/root/.bash_profile`
- `/root/.bashrc`

**Comandi eseguiti:**
```bash
# Verifica presenza umask esistente
sudo grep -n umask /root/.bash_profile /root/.bashrc 2>/dev/null

# Aggiunge umask 0027 (se non presente)
echo "umask 0027" | sudo tee -a /root/.bashrc
echo "umask 0027" | sudo tee -a /root/.bash_profile
```

## Motivazione
Un umask troppo permissivo permette la creazione di file e directory leggibili o scrivibili da utenti non autorizzati. Impostare un umask restrittivo forza una scelta consapevole sui permessi e riduce significativamente il rischio di esposizione accidentale di dati sensibili.

## Verifica 
```bash
# Verifica in entrambi i file
grep -E 'umask' /root/.bash_profile /root/.bashrc

# Verifica valore corretto
grep -E 'umask\s+0(027|077)' /root/.bash_profile /root/.bashrc || echo "Valore umask corretto non trovato"
```

**Output atteso:**
- Entrambi i file contengono `umask 0027` (o 0077)
