
# 35708 - Ensure journald log rotation is configured 

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS-6.1.1.3
**Data:** 26 Maggio 2026 
**Stato:** Pass

## Requisito del Controllo
Il servizio `systemd-journald` deve avere configurati **tutti** i parametri di rotazione dei log per evitare che i log occupino troppo spazio o diventino ingestibili.

## Fix Applicato
Abbiamo creato un file di configurazione **drop-in** (metodo ufficiale e raccomandato) invece di modificare il file principale.

**File creato:** `/etc/systemd/journald.conf.d/60-journald.conf`

**Contenuto:**
```conf
[Journal]
SystemMaxUse=500M
SystemKeepFree=100M
RuntimeMaxUse=100M
RuntimeKeepFree=50M
MaxFileSec=1month
```

**Comandi eseguiti:**
```bash
# Crea la directory drop-in (se non esiste)
sudo mkdir -p /etc/systemd/journald.conf.d/

# Crea il file di configurazione
sudo tee /etc/systemd/journald.conf.d/60-journald.conf > /dev/null << EOF
[Journal]
SystemMaxUse=500M
SystemKeepFree=100M
RuntimeMaxUse=100M
RuntimeKeepFree=50M
MaxFileSec=1month
EOF

# Ricarica la configurazione di journald
sudo systemctl restart systemd-journald
```

## Motivazione
Mantenere i log di dimensioni gestibili permette di archiviarli facilmente e di analizzarli rapidamente. Senza una rotazione corretta i log possono riempire il disco o rendere difficili le indagini forensi

## Verifica
```bash
# Verifica che tutti i parametri siano presenti
sudo grep -E '^(SystemMaxUse|SystemKeepFree|RuntimeMaxUse|RuntimeKeepFree|MaxFileSec)' /etc/systemd/journald.conf.d/60-journald.conf

# Stato del servizio
sudo systemctl status systemd-journald --no-pager | head -n 20
```

**Output atteso:**
- Tutti e 5 i parametri presenti nel file
- Nessun errore di configurazione
