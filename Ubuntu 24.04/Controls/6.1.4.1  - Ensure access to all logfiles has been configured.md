
# 35722 - Ensure access to all logfiles has been configured

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS Benchmark  | CIS-6.1.4.1
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  (Compliance - False Positive su Wazuh SCA )
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
Tutti i file di log in `/var/log` devono avere proprietario `root:root` e permessi restrittivi (almeno 640) per evitare che utenti non autorizzati possano leggere dati sensibili.

## Fix Applicato
- Cambiato proprietario di tutti i file di log in `root:root`
- Impostati permessi `640` su tutti i file in `/var/log`

**Comandi eseguiti:**
```bash
sudo find /var/log -type f -exec chown root:root {} \;
sudo find /var/log -type f -exec chmod 640 {} \;
```

## Motivazione
I file di log possono contenere informazioni sensibili (credenziali, IP, attività utenti). Limitare l’accesso solo a root riduce drasticamente il rischio di esposizione di dati.

## Verifica 
```bash
# Controllo richiesto da Wazuh
find /var/log -type f -ls
```

**Output atteso:**  
Nessun file con permessi world-readable o proprietario diverso da root.
