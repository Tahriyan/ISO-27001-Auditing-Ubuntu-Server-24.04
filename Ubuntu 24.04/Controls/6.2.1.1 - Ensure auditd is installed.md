# 35723 - Ensure auditd is installed  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS-6.2.1.1
**Stato:** Pass
**Data:** 26 Maggio 2026

## Requisito del Controllo
I pacchetti `auditd` (Linux Auditing System) e `audispd-plugins` devono essere installati sul sistema.

## Fix Applicato
- Installati i pacchetti `auditd` e `audispd-plugins` (quest’ultimo fornisce i plugin per l’invio dei log a sistemi remoti)

**Comandi eseguiti:**
```bash
sudo apt install auditd audispd-plugins -y
```

## Motivazione
La cattura degli eventi di sistema tramite auditd fornisce agli amministratori di sistema le informazioni necessarie per determinare se si stanno verificando accessi non autorizzati o altre attività sospette.

## Verifica
```bash
# Verifica installazione pacchetti
dpkg-query -s auditd | grep -E 'Status|Version'
dpkg-query -s audispd-plugins | grep -E 'Status|Version'

# Stato del servizio auditd
sudo systemctl is-enabled auditd
sudo systemctl status auditd --no-pager | head -n 15
```

**Output atteso:**
- Entrambi i pacchetti → `Status: install ok installed`
- Servizio auditd → `enabled` e `active (running)`
