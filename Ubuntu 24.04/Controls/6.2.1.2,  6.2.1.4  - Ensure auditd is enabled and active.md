# 35725-35726 - Ensure auditd is enabled and active  

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server 
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS-6.2.1.2, 6.2.1.4
**Data del fix:** 26 Maggio 2026
**Stato:** Pass

## Requisito del Controllo
Il servizio `auditd` deve essere **abilitato all’avvio** (`enabled`) e **attivo** (`active`).

## Fix Applicato
- Abilitato e avviato il servizio `auditd` con un unico comando

**Comandi eseguiti:**
```bash
sudo systemctl enable --now auditd
```

## Motivazione
La cattura degli eventi di sistema tramite auditd fornisce agli amministratori le informazioni necessarie per rilevare accessi non autorizzati o attività sospette. Se il servizio non è attivo, nessun evento viene registrato.

## Verifica
```bash
# Verifiche richieste dal CIS
sudo systemctl is-active auditd      # → active
sudo systemctl is-enabled auditd     # → enabled

# Stato completo del servizio
sudo systemctl status auditd --no-pager | head -n 20
```
