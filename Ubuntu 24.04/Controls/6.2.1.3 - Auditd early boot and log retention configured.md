
# 35723 + 35727 + 35729 - Auditd early boot and log retention configured

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS-6.2.1.3
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026

## Fix Applicato`
- Aggiunti parametri GRUB per early-boot auditing
- Configurati i parametri di retention e dimensione in `/etc/audit/auditd.conf`

**Comandi eseguiti:**
```bash
# Configurazione early boot (GRUB)
sudo sed -i 's/GRUB_CMDLINE_LINUX="/GRUB_CMDLINE_LINUX="audit=1 audit_backlog_limit=8192 /' /etc/default/grub
sudo update-grub
```

## Motivazione
Queste configurazioni garantiscono che:
- L’auditing di sistema sia attivo fin dal boot
- Non si perdano eventi di sicurezza nei primi secondi di avvio
- I log di audit abbiano uno spazio dedicato e non vengano cancellati automaticamente quando pieni

## Verifica 
```bash
# Parametri GRUB
grep audit /boot/grub/grub.cfg

# Configurazione auditd
grep -E 'max_log_file|max_log_file_action|disk_full_action' /etc/audit/auditd.conf
```
