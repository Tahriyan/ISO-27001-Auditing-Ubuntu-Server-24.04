
# 35728 - Ensure audit logs are not automatically deleted

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS-6.2.2.2
**Versione:** 1.0.0 (2024)  
**Stato:** Pass (Compliant - False Positive with Wazuh SCA)
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
I log di audit non devono essere cancellati automaticamente quando raggiungono la dimensione massima (`max_log_file_action`).

## Fix Applicato
- Impostato `max_log_file_action = ignore` in `/etc/audit/auditd.conf`

**File configurati:**
- `/etc/audit/auditd.conf`

**Comandi eseguiti:**
```bash
sudo sed -i 's/^max_log_file_action.*/max_log_file_action = ignore/' /etc/audit/auditd.conf
if ! grep -q '^max_log_file_action' /etc/audit/auditd.conf; then
    echo "max_log_file_action = ignore" | sudo tee -a /etc/audit/auditd.conf
fi
sudo systemctl restart auditd
```

## Motivazione
Impostare `ignore` impedisce la cancellazione automatica dei log di audit, garantendo che gli eventi di sicurezza non vengano persi.

## Verifica 
```bash
grep '^max_log_file_action' /etc/audit/auditd.conf
```

**Output atteso:**
```
max_log_file_action = ignore
```
