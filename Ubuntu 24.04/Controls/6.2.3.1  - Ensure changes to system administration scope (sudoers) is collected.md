# 35731 - Ensure changes to system administration scope (sudoers) is collected

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.12.4.3 | CIS Benchmark | CIS-6.2.3.1 
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
Tutte le modifiche ai file `/etc/sudoers` e `/etc/sudoers.d/` devono essere monitorate dall’auditd (tag `scope`).

## Fix Applicato
Creato il file di regola dedicato per monitorare le modifiche al sistema di privilege escalation.

**File configurati:**
- `/etc/audit/rules.d/50-scope.rules`

**Comandi eseguiti:**
```bash
sudo tee /etc/audit/rules.d/50-scope.rules << 'EOF'
-w /etc/sudoers -p wa -k scope
-w /etc/sudoers.d/ -p wa -k scope
EOF

# Carica le regole
sudo augenrules --load
```

## Motivazione
Monitorare le modifiche al file sudoers permette di rilevare eventuali alterazioni non autorizzate dei privilegi di amministrazione, fornendo una traccia audit completa.

## Verifica 
```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'sudoers|scope'

# Verifica file di regola
cat /etc/audit/rules.d/50-scope.rules
```

**Output atteso:**
```
-w /etc/sudoers -p wa -k scope
-w /etc/sudoers.d/ -p wa -k scope
```
