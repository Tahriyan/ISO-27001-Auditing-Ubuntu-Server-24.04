# 35739 - Ensure successful file system mounts are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.10 | ISO 27001:2013 A.12.4.1 | CIS-6.2.3.10
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutti i mount di filesystem eseguiti da utenti non privilegiati (`auid>=1000`). Questo rileva l’uso di dispositivi esterni o mount sospetti che potrebbero essere usati per esfiltrare dati o introdurre malware.

## Fix Applicato
File di regola già corretto e pulito (senza backslash).  

**File configurati:**  
`/etc/audit/rules.d/50-mounts.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-mounts.rules << 'EOF'
-a always,exit -F arch=b64 -S mount -F auid>=1000 -F auid!=unset -k mounts
-a always,exit -F arch=b32 -S mount -F auid>=1000 -F auid!=unset -k mounts
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
I mount eseguiti da utenti normali sono rari e spesso indicano l’inserimento di chiavette USB, dischi esterni o mount di immagini che potrebbero essere vettori di malware o esfiltrazione di dati. Il tag `mounts` permette di filtrare rapidamente questi eventi.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'mounts'

# Verifica file di regola
cat /etc/audit/rules.d/50-mounts.rules
```

**Output atteso:**
```
-a always,exit -F arch=b64 -S mount -F auid>=1000 -F auid!=unset -k mounts
-a always,exit -F arch=b32 -S mount -F auid>=1000 -F auid!=unset -k mounts
```
