# 35740 - Ensure session initiation information is collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.11 | ISO 27001:2013 A.9.4.2 | CIS-6.2.3.11
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo 
Monitorare tutti gli eventi di inizio/fine sessione di login (utmp, wtmp, btmp) per rilevare accessi sospetti, orari insoliti o tentativi di login falliti.

## Fix Applicato
File di regola già corretto e pulito (senza backslash).

**File configurati:**  
`/etc/audit/rules.d/50-session.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-session.rules << 'EOF'
-w /var/run/utmp -p wa -k session
-w /var/log/wtmp -p wa -k session
-w /var/log/btmp -p wa -k session
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
Questi file registrano login, logout, reboot e tentativi falliti. Monitorarli permette di individuare attività anomale (es. login fuori orario o da IP sconosciuti) e di correlarle con gli altri log di audit.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'session'

# Verifica file di regola
cat /etc/audit/rules.d/50-session.rules
```
