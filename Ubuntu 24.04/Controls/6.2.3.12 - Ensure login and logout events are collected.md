# 35741 - Ensure login and logout events are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.12 | ISO 27001:2013 A.8.1.3, A.9.4.2 | CIS-6.2.3.12
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutti gli eventi di login e logout del sistema, inclusi gli ultimi accessi riusciti (`lastlog`) e i tentativi falliti (`faillock`). Questo permette di rilevare attacchi brute-force o accessi sospetti.

## Fix Applicato
File di regola già corretto e pulito (senza backslash).

**File configurati:**  
`/etc/audit/rules.d/50-login.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-login.rules << 'EOF'
-w /var/log/lastlog -p wa -k logins
-w /var/run/faillock -p wa -k logins
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
I file `lastlog` e `faillock` registrano rispettivamente gli ultimi login riusciti e i tentativi falliti. Monitorarli con auditd garantisce una traccia indelebile di tutti gli accessi al sistema, utile per rilevare brute-force, account compromessi o attività anomale.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'logins'

# Verifica file di regola
cat /etc/audit/rules.d/50-login.rules
```
