# 35743 - Ensure events that modify the system's Mandatory Access Controls are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.14 | ISO 27001:2013 A.12.1.2 | CIS-6.2.3.14
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutte le modifiche ai file di configurazione di AppArmor (`/etc/apparmor/` e `/etc/apparmor.d/`). Questo rileva tentativi di alterare le policy di Mandatory Access Control (MAC) per bypassare le restrizioni di sicurezza.

## Fix Applicato
File di regola già corretto e pulito (senza backslash).

**File configurati:**  
`/etc/audit/rules.d/50-MAC-policy.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-MAC-policy.rules << 'EOF'
-w /etc/apparmor/ -p wa -k MAC-policy
-w /etc/apparmor.d/ -p wa -k MAC-policy
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
AppArmor è il sistema di Mandatory Access Control di Ubuntu. Qualsiasi modifica alle sue policy potrebbe permettere a un attaccante di elevare i privilegi o disabilitare protezioni importanti. Il tag `MAC-policy` raggruppa tutti questi eventi in modo chiaro.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'MAC-policy'

# Verifica file di regola
cat /etc/audit/rules.d/50-MAC-policy.rules
```

**Output atteso:**
```
-w /etc/apparmor/ -p wa -k MAC-policy
-w /etc/apparmor.d/ -p wa -k MAC-policy
```
