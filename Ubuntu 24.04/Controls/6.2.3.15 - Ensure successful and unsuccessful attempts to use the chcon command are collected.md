# 35744 - Ensure successful and unsuccessful attempts to use the chcon command are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.15 | ISO 27001:2013 A.12.4.1 | CIS-6.2.3.15
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutti i tentativi (riusciti e falliti) di esecuzione del comando `chcon` (change security context) da parte di utenti non privilegiati. Questo rileva possibili tentativi di modificare i contesti di sicurezza SELinux/AppArmor.

## Fix Applicato
Creato/aggiornato il file di regola dedicato per monitorare l’uso di `chcon`.

**File configurati:**  
`/etc/audit/rules.d/50-perm_chng.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-perm_chng.rules << 'EOF'
-a always,exit -F path=/usr/bin/chcon -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
Il comando `chcon` modifica il contesto di sicurezza dei file. Monitorarlo è essenziale per rilevare tentativi di aggirare i controlli di Mandatory Access Control o di alterare le policy di protezione.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'perm_chng|chcon'

# Verifica file di regola
cat /etc/audit/rules.d/50-perm_chng.rules
```

**Output atteso:**
```
-a always,exit -F path=/usr/bin/chcon -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
```
