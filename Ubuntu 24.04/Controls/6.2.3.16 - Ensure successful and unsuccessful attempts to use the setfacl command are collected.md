# 35745 - Ensure successful and unsuccessful attempts to use the setfacl command are collected

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.16 | ISO 27001:2013 A.12.4.1 | CIS-6.2.3.16
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutti i tentativi (riusciti e falliti) di esecuzione del comando `setfacl` (set file ACL) da parte di utenti non privilegiati. Questo rileva modifiche alle Access Control List estese sui file.

## Fix Applicato
Aggiunta (append) la regola per `setfacl` al file esistente `/etc/audit/rules.d/50-perm_chng.rules` (che già conteneva la regola per `chcon`).  
In questo modo tutte le modifiche ai permessi/ACL sono raggruppate nello stesso file.

**File configurati:**  
`/etc/audit/rules.d/50-perm_chng.rules`

**Comandi eseguiti:**

```bash
sudo tee -a /etc/audit/rules.d/50-perm_chng.rules << 'EOF'
-a always,exit -F path=/usr/bin/setfacl -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
`setfacl` permette di impostare ACL estese sui file. Monitorare il suo utilizzo è fondamentale per rilevare tentativi di alterare i permessi in modo non standard (bypass di permessi base o escalation).

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'perm_chng|setfacl|chcon'

# Verifica file di regola completo
cat /etc/audit/rules.d/50-perm_chng.rules
```

**Output atteso:**
```
-a always,exit -F path=/usr/bin/chcon -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
-a always,exit -F path=/usr/bin/setfacl -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
```
