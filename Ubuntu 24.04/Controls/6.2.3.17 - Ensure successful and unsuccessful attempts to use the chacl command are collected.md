# 35746 - Ensure successful and unsuccessful attempts to use the chacl command are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.17 | ISO 27001:2013 A.12.4.1
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutti i tentativi (riusciti e falliti) di esecuzione del comando `chacl` (change ACL) da parte di utenti non privilegiati. `chacl` è un comando di compatibilità IRIX/XFS per gestire le Access Control List.

## Fix Applicato
Aggiunta (append) la regola per `chacl` al file esistente `/etc/audit/rules.d/50-perm_chng.rules` (che ora contiene `chcon`, `setfacl` e `chacl`).

**File configurati:**  
`/etc/audit/rules.d/50-perm_chng.rules`

**Comandi eseguiti:**

```bash
sudo tee -a /etc/audit/rules.d/50-perm_chng.rules << 'EOF'
-a always,exit -F path=/usr/bin/chacl -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
`chacl` permette di modificare le ACL su file e directory. Monitorare il suo utilizzo (insieme a `chcon` e `setfacl`) garantisce che qualsiasi modifica alle ACL estese sia tracciata, rilevando potenziali tentativi di alterare i permessi in modo non standard.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'perm_chng|chacl|setfacl|chcon'

# Verifica file di regola completo
cat /etc/audit/rules.d/50-perm_chng.rules
```

**Output atteso:**
```
-a always,exit -F path=/usr/bin/chcon -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
-a always,exit -F path=/usr/bin/setfacl -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
-a always,exit -F path=/usr/bin/chacl -F perm=x -F auid>=1000 -F auid!=unset -k perm_chng
```
