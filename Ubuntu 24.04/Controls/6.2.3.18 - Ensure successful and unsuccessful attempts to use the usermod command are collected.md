# 35747 - Ensure successful and unsuccessful attempts to use the usermod command are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.18 | ISO 27001:2013 A.12.4.1
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo 
Monitorare tutti i tentativi (riusciti e falliti) di esecuzione del comando `usermod` da parte di utenti non privilegiati. Questo comando modifica gli account di sistema (username, UID, GID, home, shell, ecc.).

## Fix Applicato
Creato un nuovo file di regola dedicato per monitorare l’uso di `usermod`.

**File configurati:**  
`/etc/audit/rules.d/50-usermod.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-usermod.rules << 'EOF'
-a always,exit -F path=/usr/sbin/usermod -F perm=x -F auid>=1000 -F auid!=unset -k usermod
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione 
`usermod` è uno dei comandi più sensibili per la modifica degli account utente. Monitorarlo garantisce che qualsiasi cambiamento (creazione di backdoor, modifica di privilegi, ecc.) venga registrato in modo indelebile nei log di audit.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'usermod'

# Verifica file di regola
cat /etc/audit/rules.d/50-usermod.rules
```

**Output atteso:**
```
-a always,exit -F path=/usr/sbin/usermod -F perm=x -F auid>=1000 -F auid!=unset -k usermod
```
