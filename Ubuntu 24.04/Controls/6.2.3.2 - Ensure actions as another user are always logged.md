# 35732 - Ensure actions as another user are always logged

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.9.4.2 | CIS-6.2.3.2
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
Tutte le azioni eseguite con privilegi elevati (sudo / su / execve con euid diverso da uid) devono essere registrate dall’auditd (tag `user_emulation`).

## Fix Applicato
Creato il file di regola dedicato per monitorare l’emulazione utente (azioni come altro utente).

**File configurati:**
- `/etc/audit/rules.d/50-user_emulation.rules`

**Comandi eseguiti:**
```bash
sudo tee /etc/audit/rules.d/50-user_emulation.rules << 'EOF'
-a always,exit -F arch=b64 -C euid!=uid -F auid!=unset -S execve -k user_emulation
-a always,exit -F arch=b32 -C euid!=uid -F auid!=unset -S execve -k user_emulation
EOF

# Carica le regole
sudo augenrules --load
```

## Motivazione
Questa regola garantisce che ogni volta che un utente esegue un comando con privilegi diversi dai propri (ad esempio tramite `sudo`), l’evento venga registrato in modo indelebile. È fondamentale per tracciare azioni privilegiate e correlarle con i log di sudo.

## Verifica 
```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'user_emulation|execve'

# Verifica file di regola
cat /etc/audit/rules.d/50-user_emulation.rules
```

**Output atteso:**
```
-a always,exit -F arch=b64 -C euid!=uid -F auid!=unset -S execve -k user_emulation
-a always,exit -F arch=b32 -C euid!=uid -F auid!=unset -S execve -k user_emulation
```
