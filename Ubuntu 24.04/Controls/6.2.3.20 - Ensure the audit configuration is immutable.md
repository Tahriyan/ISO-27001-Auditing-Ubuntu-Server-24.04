# 35749 - Ensure the audit configuration is immutable
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.20 | ISO 27001:2013 A.12.4.1
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo  
Rendere la configurazione di audit **immutabile** (`-e 2`). Una volta attivata, nessuna regola può più essere modificata o cancellata finché il sistema non viene riavviato. Questo impedisce a un attaccante di disabilitare o alterare l’audit per nascondere le proprie attività.

**⚠️ Avvertenza importante**  
Questa regola deve essere **l’ultima** (file `99-finalize.rules`). Dopo averla caricata, le regole di audit diventano immutabili fino al prossimo reboot.

## Fix Applicato
Creato il file finale che imposta la modalità immutable.

**File configurati:**  
`/etc/audit/rules.d/99-finalize.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/99-finalize.rules << 'EOF'
-e 2
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
In modalità immutable (`-e 2`) un attaccante non può più usare `auditctl` per rimuovere o modificare le regole di audit. L’unica possibilità per cambiare la configurazione è riavviare il sistema (cosa che verrebbe notata dagli amministratori).

## Verifica

```bash
# Verifica stato attuale (deve mostrare "enabled 2")
sudo auditctl -s | grep enabled

# Verifica file di regola
cat /etc/audit/rules.d/99-finalize.rules
```

**Output atteso:**
```
enabled 2
-e 2
```
