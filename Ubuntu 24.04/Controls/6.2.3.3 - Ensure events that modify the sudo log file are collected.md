# 35733 - Ensure events that modify the sudo log file are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.3 | ISO 27001:2013 A.9.4.2  
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutte le modifiche al file di log di sudo (`/var/log/sudo.log`). Questo permette di tracciare ogni comando eseguito con privilegi elevati e rilevare eventuali tentativi di tampering.

## Fix Applicato  
Creato il file di regola dedicato per monitorare il log di sudo.  

**File configurati:**  
`/etc/audit/rules.d/50-sudo.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-sudo.rules << 'EOF'
-w /var/log/sudo.log -p wa -k sudo_log_file
EOF

# Carica le regole
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
Ogni volta che un amministratore esegue un comando con `sudo`, l’evento viene scritto sia sul log di sudo sia sul log di auditd. Questo controllo garantisce la correlazione tra i due log e rileva eventuali manipolazioni del file di log.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'sudo_log_file'

# Verifica file di regola
cat /etc/audit/rules.d/50-sudo.rules
```

**Output atteso:**
```
-w /var/log/sudo.log -p wa -k sudo_log_file
```
