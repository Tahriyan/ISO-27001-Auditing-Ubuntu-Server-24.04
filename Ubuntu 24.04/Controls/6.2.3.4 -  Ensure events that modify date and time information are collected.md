# 35734 - Ensure events that modify date and time information are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.4 | ISO 27001:2013 A.12.1.2 | CIS-6.2.3.4
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutte le modifiche alla data/ora di sistema (adjtimex, settimeofday, clock_settime, stime, ecc.) per rilevare attività malevole o tentativi di alterare i timestamp.

## Fix Applicato 
Creato/aggiornato il file di regola con la versione completa e ottimizzata (incluse le condizioni `-F a0=0x0` per `clock_settime`).

**File configurati:**  
`/etc/audit/rules.d/50-time-change.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-time-change.rules << 'EOF'
-a always,exit -F arch=b64 -S adjtimex,settimeofday,clock_settime -k time-change
-a always,exit -F arch=b32 -S adjtimex,settimeofday,stime,clock_settime -k time-change
-a always,exit -F arch=b64 -S clock_settime -F a0=0x0 -k time-change
-a always,exit -F arch=b32 -S clock_settime -F a0=0x0 -k time-change
-w /etc/localtime -p wa -k time-change
EOF

# Carica le regole
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
Le modifiche alla data/ora di sistema possono essere usate per nascondere attività malevole o falsificare i log. Questa regola cattura tutti i system call rilevanti in modo completo.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'time-change'

# Verifica file di regola
cat /etc/audit/rules.d/50-time-change.rules
```
