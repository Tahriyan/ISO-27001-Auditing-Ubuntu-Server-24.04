# 35737 - Ensure events that modify user/group information are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.8 | ISO 27001:2013 A.12.4.3
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo  
Monitorare tutte le modifiche ai file che contengono informazioni su utenti, gruppi, password e meccanismi di autenticazione (PAM, NSS). Qualsiasi modifica imprevista a questi file può indicare un tentativo di backdoor o compromissione degli account.

## Fix Applicato
Aggiornato il file di regola aggiungendo i tre elementi mancanti richiesti dal benchmark CIS:  
- `/etc/nsswitch.conf`  
- `/etc/pam.conf`  
- `/etc/pam.d` (directory)

**File configurati:**  
`/etc/audit/rules.d/50-identity.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-identity.rules << 'EOF'
-w /etc/group -p wa -k identity
-w /etc/passwd -p wa -k identity
-w /etc/gshadow -p wa -k identity
-w /etc/shadow -p wa -k identity
-w /etc/security/opasswd -p wa -k identity
-w /etc/nsswitch.conf -p wa -k identity
-w /etc/pam.conf -p wa -k identity
-w /etc/pam.d -p wa -k identity
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
Questi file controllano come il sistema risolve utenti/gruppi (NSS) e gestisce l’autenticazione (PAM). Modificarli permette a un attaccante di creare account nascosti o bypassare i controlli di login. Il tag `identity` raggruppa tutti questi eventi in modo chiaro nei log di audit.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'identity'

# Verifica file di regola
cat /etc/audit/rules.d/50-identity.rules
```
