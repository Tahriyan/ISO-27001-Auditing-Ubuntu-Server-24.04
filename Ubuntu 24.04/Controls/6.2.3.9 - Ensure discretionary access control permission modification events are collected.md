# 35738 - Ensure discretionary access control permission modification events are collected
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.3.9 | ISO 27001:2013 A.12.1.2 | CIS-6.2.3.9
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
Monitorare tutte le modifiche ai permessi, ownership e attributi estesi dei file (chmod, chown, setxattr, ecc.) effettuate da utenti non privilegiati. Questo rileva tentativi di privilege escalation o alterazione dei permessi da parte di un attaccante.

## Fix Applicato
File già corretto e pulito (senza backslash `\` sulle righe spezzate).  
Abbiamo sostituito la versione precedente (che conteneva i backslash) con la versione singola-riga, come richiesto dal benchmark.

**File configurati:**  
`/etc/audit/rules.d/50-perm_mod.rules`

**Comandi eseguiti:**

```bash
sudo tee /etc/audit/rules.d/50-perm_mod.rules << 'EOF'
-a always,exit -F arch=b64 -S chmod,fchmod,fchmodat -F auid>=1000 -F auid!=unset -k perm_mod
-a always,exit -F arch=b64 -S chown,fchown,lchown,fchownat -F auid>=1000 -F auid!=unset -k perm_mod
-a always,exit -F arch=b64 -S setxattr,lsetxattr,fsetxattr,removexattr,lremovexattr,fremovexattr -F auid>=1000 -F auid!=unset -k perm_mod
-a always,exit -F arch=b32 -S chmod,fchmod,fchmodat -F auid>=1000 -F auid!=unset -k perm_mod
-a always,exit -F arch=b32 -S chown,fchown,lchown,fchownat -F auid>=1000 -F auid!=unset -k perm_mod
-a always,exit -F arch=b32 -S setxattr,lsetxattr,fsetxattr,removexattr,lremovexattr,fremovexattr -F auid>=1000 -F auid!=unset -k perm_mod
EOF

# Carica le regole e riavvia auditd
sudo augenrules --load
sudo systemctl restart auditd
```

## Motivazione
Le modifiche ai permessi dei file sono uno dei metodi più comuni usati dagli attaccanti per ottenere accesso persistente o elevare i privilegi. Il tag `perm_mod` permette di filtrare rapidamente questi eventi nei log di audit.

## Verifica

```bash
# Verifica regole attive
sudo auditctl -l | grep -E 'perm_mod'

# Verifica file di regola
cat /etc/audit/rules.d/50-perm_mod.rules
```
