# 35757 - Ensure audit tools are group-owned by root  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.9.1.1 | CIS-6.2.4.10
**Data del fix:** 26 Maggio 2026 
**Stato:** Pass


## Requisito del Controllo
Tutti gli strumenti d audit (`auditctl`, `aureport`, `ausearch`, `autrace`, `auditd`, `augenrules`) devono avere come **gruppo proprietario** `root`.

## Fix Applicato
- Cambiato il group ownership di tutti gli strumenti di audit a `root`

**Comandi eseguiti:**
```bash
sudo chgrp root /sbin/auditctl /sbin/aureport /sbin/ausearch \
/sbin/autrace /sbin/auditd /sbin/augenrules
```

## Motivazione
Proteggere gli strumenti di audit (sia owner che group) e' necessario per impedire a utenti non autorizzati di modificare o utilizzare questi tool per alterare o nascondere i record di auditing

## Verifica
```bash
# Verifica CIS richiesta (group root per tutti i tool)
sudo stat -Lc "%G %n" /sbin/auditctl /sbin/aureport /sbin/ausearch \
/sbin/autrace /sbin/auditd /sbin/augenrules
```

**Output atteso:**
```
root /sbin/auditctl
root /sbin/aureport
root /sbin/ausearch
root /sbin/autrace
root /sbin/auditd
root /sbin/augenrules
```
