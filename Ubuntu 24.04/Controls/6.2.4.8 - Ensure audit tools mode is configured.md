# 35755 - Ensure audit tools mode is configured
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.4.8 | ISO 27001:2013 A.9.1.1 
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  (Compliant - False Positive with Wazuh SCA)
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
I tool di audit (`auditctl`, `aureport`, `ausearch`, `autrace`, `auditd`, `augenrules`) devono avere permessi restrittivi per impedire a utenti non-root di modificarli o sostituirli.

## Fix Applicato
Rimossi i permessi di scrittura per group e others (`go-w`) sui binari di audit.  
Impostati esplicitamente a `750` (rwxr-x--- root:root) per maggiore sicurezza.

**File/binari configurati:**  
`/sbin/auditctl`, `/sbin/aureport`, `/sbin/ausearch`, `/sbin/autrace`, `/sbin/auditd`, `/sbin/augenrules`

**Comandi eseguiti:**

```bash
sudo chmod 750 /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/augenrules
sudo chown root:root /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/augenrules
```

## Motivazione
Se un attaccante riuscisse a modificare questi tool, potrebbe disabilitare l’audit o nascondere le proprie attività. Proteggerli con permessi stretti è fondamentale per mantenere l’integrità del sistema di auditing.

## Verifica

```bash
# Verifica permessi attuali
sudo stat -c "%n %a" /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/augenrules

# Verifica proprietario e gruppo
sudo ls -l /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/augenrules
```
