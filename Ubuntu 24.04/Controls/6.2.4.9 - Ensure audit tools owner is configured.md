# 35756 - Ensure audit tools owner is configured  
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.2.4.9 | ISO 27001:2013 A.9.1.1
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo  
Tutti i tool di audit (`auditctl`, `aureport`, `ausearch`, `autrace`, `auditd`, `augenrules`) devono appartenere all’utente **root**. Questo impedisce a utenti non privilegiati di sostituirli o modificarli.

## Fix Applicato
Impostato correttamente il proprietario `root` sui binari di audit (comando già eseguito in precedenza).

**File/binari configurati:**  
`/sbin/auditctl`, `/sbin/aureport`, `/sbin/ausearch`, `/sbin/autrace`, `/sbin/auditd`, `/sbin/augenrules`

**Comandi eseguiti:**

```bash
sudo chown root:root /sbin/auditctl /sbin/aureport /sbin/ausearch \
/sbin/autrace /sbin/auditd /sbin/augenrules
```

## Motivazione
Se un attaccante riuscisse a cambiare proprietario di questi tool, potrebbe sostituirli con versioni malevole per disabilitare l’audit o nascondere le proprie attività. Il proprietario `root` garantisce che solo l’amministratore di sistema possa gestirli.

## Verifica

```bash
# Verifica proprietario (deve essere root per tutti)
sudo stat -Lc "%U" /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/augenrules

# Verifica dettagli completi
sudo ls -l /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/augenrules
```
