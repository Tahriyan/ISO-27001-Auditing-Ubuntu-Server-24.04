# 35759 - Ensure filesystem integrity is regularly checked
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.3.2 | ISO 27001:2013 A.12.4.3
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 28 Maggio 2026  

## Requisito del Controllo
AIDE deve eseguire un controllo completo dell’integrità del filesystem **ogni giorno** in modo automatico.  
Il benchmark CIS si aspetta l’uso del **systemd timer** ufficiale (`dailyaidecheck.timer`) fornito dal pacchetto `aide-common`.

## Fix Applicato
Smascherati e abilitati i due unit systemd ufficiali di AIDE (`dailyaidecheck.service` e `dailyaidecheck.timer`).

**Comandi eseguiti:**

```bash
# Sblocca gli unit (potrebbero essere masked di default)
sudo systemctl unmask dailyaidecheck.timer dailyaidecheck.service

# Abilita e avvia immediatamente il timer
sudo systemctl --now enable dailyaidecheck.timer
```

## Motivazione
Un controllo giornaliero automatico di AIDE permette di rilevare rapidamente modifiche non autorizzate a file critici (binari, librerie, configurazioni di sistema, ecc.). Usare il timer systemd ufficiale garantisce che il controllo sia gestito dal sistema in modo affidabile e con logging corretto.

## Verifica

```bash
# Verifica lo stato del service e del timer
sudo systemctl show dailyaidecheck.service
sudo systemctl show dailyaidecheck.timer

# Verifica che il timer sia attivo
sudo systemctl status dailyaidecheck.timer --no-pager

# (Opzionale) Forza un controllo manuale per test
sudo aide --check
```

**Output atteso (principali righe):**
```
LoadState=loaded
UnitFileState=static
ActiveState=active
```
