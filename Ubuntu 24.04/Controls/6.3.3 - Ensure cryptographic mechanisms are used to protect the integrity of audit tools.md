# 35760 - Ensure cryptographic mechanisms are used to protect the integrity of audit tools

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 6.3.3  
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 29 Maggio 2026  

## Requisito del Controllo
AIDE deve monitorare i tool di audit con un meccanismo crittografico forte (`sha512`) per rilevare eventuali modifiche o sostituzioni malevole.

## Fix Applicato
Aggiunte le regole **corrette** direttamente in `/etc/aide/aide.conf` usando i percorsi reali (`/usr/sbin/`) e l’hash `sha512`.  
Rinizializzato il database AIDE.

**File configurati:**  
`/etc/aide/aide.conf`

**Comandi eseguiti:**

```bash
sudo bash -c '
cat >> /etc/aide/aide.conf << EOF

# Audit Tools - integrità crittografica (CIS 6.3.3)
$(readlink -f /sbin/auditctl) p+i+n+u+g+s+b+acl+xattrs+sha512
$(readlink -f /sbin/auditd) p+i+n+u+g+s+b+acl+xattrs+sha512
$(readlink -f /sbin/ausearch) p+i+n+u+g+s+b+acl+xattrs+sha512
$(readlink -f /sbin/aureport) p+i+n+u+g+s+b+acl+xattrs+sha512
$(readlink -f /sbin/autrace) p+i+n+u+g+s+b+acl+xattrs+sha512
$(readlink -f /sbin/augenrules) p+i+n+u+g+s+b+acl+xattrs+sha512
EOF
'

sudo aide --init --config /etc/aide/aide.conf
sudo cp /var/lib/aide/aide.db.new /var/lib/aide/aide.db
```

## Motivazione
Proteggere i tool di audit con hash crittografico impedisce a un attaccante di sostituirli o modificarli senza essere rilevato da AIDE.

## Verifica

```bash
sudo grep -E 'auditctl|auditd|ausearch|aureport|autrace|augenrules' /etc/aide/aide.conf
sudo aide --config-check --config /etc/aide/aide.conf
```
