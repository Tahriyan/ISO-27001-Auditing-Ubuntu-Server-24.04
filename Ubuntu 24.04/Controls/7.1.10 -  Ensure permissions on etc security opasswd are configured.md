# 35770 - Ensure permissions on /etc/security/opasswd are configured
**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** CIS 7.1.10 | ISO 27001:2013 A.9.1.1
**Versione:** 1.0.0 (2024)  
**Stato:** Pass  
**Data del fix:** 29 Maggio 2026  

## Requisito del Controllo
I file `/etc/security/opasswd` e `/etc/security/opasswd.old` (che contengono le vecchie password degli utenti quando si usa `pam_pwhistory` o `pam_unix`) devono avere permessi **600 root:root** per impedire la lettura da parte di utenti normali.

## Fix Applicato
Creati i file (se non esistevano) e impostati i permessi e proprietario corretti.

**File configurati:**  
`/etc/security/opasswd`  
`/etc/security/opasswd.old`

**Comandi eseguiti:**

```bash
sudo touch /etc/security/opasswd /etc/security/opasswd.old
sudo chown root:root /etc/security/opasswd /etc/security/opasswd.old
sudo chmod 600 /etc/security/opasswd /etc/security/opasswd.old
```

## Motivazione
Questi file contengono hash di password precedenti. Se fossero leggibili da utenti normali, un attaccante potrebbe usarli per cracking offline o per ricostruire la storia delle password degli utenti.

## Verifica

```bash
# Verifica permessi e proprietario
sudo stat -c "%a %U %G" /etc/security/opasswd /etc/security/opasswd.old

# Verifica dettagli completi
sudo ls -l /etc/security/opasswd /etc/security/opasswd.old
```

**Output atteso:**
```
600 root root
600 root root

-rw------- 1 root root ... /etc/security/opasswd
-rw------- 1 root root ... /etc/security/opasswd.old
```
