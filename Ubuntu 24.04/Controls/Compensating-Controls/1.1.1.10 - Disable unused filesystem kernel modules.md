
# 35509 - Disable unused filesystem kernel modules  

**Profilo CIS:** CIS Ubuntu Linux 24.04 LTS Benchmark for Level 1 - Server
**Versione:** 1.0.0 (2024)
**Riferimento Compliance:** ISO 27001:2013 A.13.1.3 | CIS Benchmark Ubuntu | CIS-1.1.1.10
**Data:** 26 Maggio 2026 
**Stato:** Failed
**Stato compensating control:** Partially Compliant / Compensated

## Requisito del Controllo
Disabilitare i kernel modules dei filesystem non necessari per ridurre la superficie di attacco locale del kernel. Molti di questi moduli hanno CVE note e possono essere sfruttati da rootkit per nascondere processi o file.

## Mitigazione Applicata
È stato creato un file di configurazione in `/etc/modprobe.d/` che impedisce il caricamento automatico e forza il fallimento di tutti i moduli filesystem con vulnerabilità note.

**File creato:** `/etc/modprobe.d/disable-uncommon-fs.conf`

**Contenuto del file:**
```bash
install afs /bin/false
install ceph /bin/false
install cifs /bin/false
install exfat /bin/false
install fat /bin/false
install fscache /bin/false
install gfs2 /bin/false
install nfs_common /bin/false
install nfsd /bin/false
install smbfs_common /bin/false

blacklist afs
blacklist ceph
blacklist cifs
blacklist exfat
blacklist fat
blacklist fscache
blacklist gfs2
blacklist nfs_common
blacklist nfsd
blacklist smbfs_common
```

**Comandi eseguiti:**
- Creazione del file di configurazione
- Rimozione dei moduli già caricati in memoria (`modprobe -r`)

## Eccezioni e Motivazione
Sono stati esclusi i seguenti moduli per motivi di compatibilità obbligatori:
- `fuse` → richiesto da Nextcloud Snap
- moduli `ext*` → necessari per il filesystem root del sistema

## Riduzione del Rischio Ottenuta
- Eliminazione di 11 kernel modules con CVE note (afs, ceph, cifs, exfat, fat, fscache, gfs2, nfs_common, nfsd, smbfs_common)
- Riduzione significativa della superficie di attacco del kernel
- Prevenzione del caricamento dinamico di moduli potenzialmente abusabili da parte di malware/rootkit

## Rischio Residuo
**Basso**  
Rimangono attivi solo i moduli strettamente necessari (fuse + ext). Il rischio residuo è monitorato tramite Wazuh e verrà rivalutato in caso di aggiornamenti del kernel o di Nextcloud
