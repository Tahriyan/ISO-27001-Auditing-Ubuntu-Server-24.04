# 35709-35711 - Ensure systemd-journal-remote and systemd-journal-upload are not used

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS-6.1.2.1.x  
**Versione:** 1.0.0 (2024)  
**Stato:** Pass (Compliant via Alternative Control)  
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
- **35709**: `systemd-journal-remote` deve essere installato  
- **35710**: `systemd-journal-upload` deve essere configurato con autenticazione TLS  
- **35711**: `systemd-journal-upload` deve essere abilitato e attivo  

Queste regole fanno parte del percorso di forwarding log verso host remoti tramite journald.

## Fix Applicato
**Rimossi intenzionalmente** (pulizia del sistema):
- Pacchetto `systemd-journal-remote` (e relative dipendenze)
- Configurazione e servizio `systemd-journal-upload` (mai attivato)

**Configurazione attuale:**
- Solo `systemd-journald` come logger primario
- Forwarding verso rsyslog disabilitato (`ForwardToSyslog=no`)
- Log centralizzati e monitorati tramite **Wazuh Agent** (modulo `imjournal`)

**Comandi eseguiti:**
```bash
sudo systemctl stop rsyslog && sudo systemctl disable --now rsyslog && sudo systemctl mask rsyslog
sudo apt purge -y rsyslog systemd-journal-remote
sudo apt autoremove -y
sudo sed -i 's/^ForwardToSyslog=yes/ForwardToSyslog=no/' /etc/systemd/journald.conf
sudo systemctl restart systemd-journald
```

## Motivazione
`systemd-journal-remote` e `systemd-journal-upload` sono meccanismi legacy/alternativi di forwarding log.  
Nel nostro setup abbiamo scelto una soluzione **più moderna, leggera e sicura**:
- `systemd-journald` come unico logger
- `Wazuh Agent` per la raccolta, integrità, compressione e invio centralizzato dei log

Questa architettura elimina doppioni inutili, riduce la superficie di attacco e garantisce comunque centralizzazione e protezione dei log (compensating control pienamente valido).

## Verifica 
```bash
# Pacchetti rimossi
dpkg -l | grep -E 'rsyslog|systemd-journal-remote' || echo "Pacchetti rimossi correttamente"

# journal-upload non configurato
cat /etc/systemd/journal-upload.conf /etc/systemd/journal-upload.conf.d/*.conf 2>/dev/null || echo "journal-upload non configurato"

# Stato servizi
systemctl is-active systemd-journald
systemctl is-active wazuh-agent
```

**Output atteso:**
```
Pacchetti rimossi correttamente
journal-upload non configurato
active
active
```
