
# 35716-35717, 35719-35720 - Ensure rsyslog is not installed, not active and not configured

**Profilo:** CIS Ubuntu Linux 24.04 LTS Benchmark – Level 1 Server  
**Riferimento Compliance:** ISO 27001:2013 A.12.4.1 | CIS Benchmark | CIS-6.1.3.x
**Versione:** 1.0.0 (2024)  
**Stato:** Pass (Compliant via Alternative Control)
**Data del fix:** 28 Maggio 2026

## Requisito del Controllo
Le regole CIS richiedono:
- **35716**: Installazione di `rsyslog`
- **35717**: Servizio `rsyslog` abilitato e attivo
- **35719**: Configurazione della modalità di creazione dei file di log (`$FileCreateMode 0640` o più restrittivo)
- **35720**: Configurazione di `rsyslog` per inviare i log a un host remoto

## Fix Applicato
**Rimossi intenzionalmente** (pulizia del sistema):
- Pacchetto `rsyslog` (e relative dipendenze)
- Tutti i file di configurazione in `/etc/rsyslog.d/`

**Configurazione attuale:**
- Solo `systemd-journald` come logger primario
- `ForwardToSyslog=no`
- Log raccolti, monitorati e inviati centralmente tramite **Wazuh Agent** (modulo `imjournal`)

**Comandi eseguiti:**
```bash
sudo systemctl stop rsyslog
sudo systemctl disable --now rsyslog
sudo systemctl mask rsyslog
sudo apt purge -y rsyslog
sudo apt autoremove -y
sudo systemctl restart systemd-journald
```

## Motivazione
`rsyslog` è un tool legacy per la gestione dei log.  
Nel nostro setup abbiamo scelto un’architettura **moderna, più semplice e sicura** basata su:
- `systemd-journald` (nativo, binario, con compressione e rate limiting)
- `Wazuh Agent` (raccolta in tempo reale, integrità, invio sicuro al manager)

Questa scelta elimina doppioni inutili, riduce la superficie di attacco e garantisce tutti i requisiti di centralizzazione, integrità e protezione dei log richiesti dal benchmark CIS

## Verifica 
```bash
# Verifica rimozione rsyslog
dpkg -l | grep rsyslog || echo "rsyslog NON installato"

# Verifica assenza file di configurazione rsyslog
ls /etc/rsyslog.d/ 2>/dev/null || echo "Directory /etc/rsyslog.d vuota o assente"

# Stato journald + Wazuh (compensating control)
grep '^ForwardToSyslog' /etc/systemd/journald.conf
systemctl is-active systemd-journald
systemctl is-active wazuh-agent
```

**Output atteso:**
```
rsyslog NON installato
Directory /etc/rsyslog.d vuota o assente
ForwardToSyslog=no
active
active
```
